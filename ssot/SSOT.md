## §1-B. 시계열 취득·스캔 규약 (불가침)

> **신설 계기**: 2026-08-01~08-23 FRED 전체 시계열 접근 실패(3주 연속)로 관측 시퀀스가 3~4개로 축약되어 원칙⑨ 스캔이 구조적으로 불가능해졌다. 그 결과 S7 활성 구간 2회(08-10~08-11, 08-17~08-18)가 누락되었고, **2026-08-17자 카운트 7/8(폭락 임박)이 인지되지 않았다.** 상세는 `MS_재정통보_2026-08-24_S7소급_및_판정규약개정.md`.

**B-1. 취득 주체와 방법**
정량 신호(S4·S6·S7·S8)의 컷값·z-score·판정은 **코드 실행 환경에서 `sentinel_compute.py`로 산출**한다. 웹 가져오기 도구만으로 CSV를 파싱하려는 시도는 금지한다 — `application/csv` MIME 타입이 "binary data"로 반환되어 실패하며, 이것이 2026-08 실패의 직접 원인이다.

**B-2. 스캔 범위 (핵심)**
매 실행은 **직전 확정일의 익영업일부터 최신 관측일까지 전 영업일**을 원칙⑨로 **연속 스캔**한다.
- "최근 N관측만 나열"하는 축약을 **금지**한다.
- 스캔 구간에서 발견된 활성/해제 확정은 **발생일로 소급 기록**하며, 발견일로 기록하지 않는다.
- 컷값이 이월 상태여도 **스캔 자체는 반드시 수행**한다.

**B-3. 실패 시 행동 — 판정 유보(carry)**
시계열 취득 실패 시 해당 신호는 **`판정유보(carry)`**로 기록하고 `02_교환소`에 알림을 발령한다.
- 이월 컷값 또는 축약된 시퀀스를 근거로 **'활성 확정' 또는 '비활성 확정'을 선언할 수 없다.**
- 판정유보 신호는 카운트에서 **직전 확정 상태를 그대로 승계**하며, 카드에 `(유보, 직전확정 승계)`를 명기한다.
- 판정유보가 **2회 연속** 발생하면 긴급도 '최고'로 격상한다.

**B-4. 소스 이중화 (2026-08-26 갱신)**

| 신호 | 소스 체인 (좌→우 순차) |
|---|---|
| S4 VIXCLS | CBOE 원발행처 → FRED API → FRED web → Yahoo(2차) |
| S7 BAMLH0A0HYM2 | FRED API → FRED web → 로컬 캐시 |
| S8 DTWEXBGS | 연준 H.10 → FRED API → FRED web |
| S6 P/C | CBOE 일자별 JSON(`cdn.cboe.com/data/us/options/market_statistics/daily/{YYYY-MM-DD}_daily_options`) → 저장소 누적 캐시 `cache_CBOE_TOTALPC.csv`. 매 실행은 마지막 누적일 이후 영업일만 추가 취득하며, 휴장일·미게시일(403)은 건너뜀 (2026-09-28 복구) |

- **S7(HY OAS)은 원발행처가 ICE 라이선스 계열이어서 무료 대체 배포처가 FRED뿐이다.** 캐시가 최후 방어선이며, 매 성공 취득 시 전체 시계열을 캐시에 덮어쓴다.
- 2차·캐시 사용 시 카드에 **소스명을 반드시 명기**한다(1차 아님을 은폐 금지).

**B-5. 운영 제약 — FRED 레이트 리밋**
FRED는 단시간 반복 호출에 **HTTP 503**으로 응답한다(2026-08-24 실측: 약 10회 연속 호출 후 차단). 따라서 취득은 **1일 1회**를 원칙으로 하고, 동일 세션 내 재산출은 캐시를 사용한다. 실패 시 지수 백오프 재시도(5s/15s/30s/45s)를 적용한다.

**B-6. 산출물 보존**
매 실행은 `snapshot_YYYY-MM-DD.json`(전체 결과)과 `cache_<SERIES>.csv`(시계열)를 남긴다. 스냅샷은 사후 재구성·감사용이며, 카드 이력을 대체하지 않는다.

**B-7. 엔진 무결성 (v3 신설)**
`sentinel_compute.py`는 저장소 `engine/`에 두고 변경은 PR로만 한다. 파일을 옮겨 적는 과정에서 값 수준 손상이 조용히 발생한 전례(2026-08-30, 동일 파일 2회 재현)가 있으므로, 엔진 변경 PR은 **변경 전후 sha256을 `CHANGELOG.md`에 기록**하고 **회귀 픽스처(`engine/sentinel_fixture.py`) 통과**를 병합 요건으로 한다. (2026-09-28 개정: 옛 문언의 드라이브 전사·위클리 프롬프트 절차는 폐지됨)

**⑥ 롤링 윈도우 정의**: 롤링 윈도우는 **수신한 전체 시계열을 로컬에서 기준일 기산 슬라이싱**하여 확정한다. 3Y = 최근 1,096일, 1Y = 최근 365일(달력일 기준, 영업일 관측치만 사용).
> **개정 사유 (실측 2026-08-24)**: v1의 "FRED 기본 3Y 시계열" 정의는 성립하지 않는다. `fredgraph.csv`의 기본 반환 범위가 계열마다 다르기 때문이다 — `VIXCLS` 1990~(n=9,256), `BAMLH0A0HYM2` 3Y(n=787), `DTWEXBGS` 2006~(n=5,169). 또한 `cosd` 파라미터는 계열에 따라 **무시된다**. 따라서 엔드포인트 파라미터에 윈도우를 위임할 수 없다.

**⑦ S6 처리 — 재캘리브레이션과 결번 (2026-09-28 개정)**

*(가) 재캘리브레이션 완료.* 종전 임계 「20일 평균 <0.74」는 2006–2019 CBOE 아카이브 기반 임시 임계였으며, 2022-01~2026-09 실측에서 20일 평균의 최저값이 0.778로 한 번도 도달하지 않아 신호가 사실상 영구 비활성이었다. 2026-09-28 사용자 결정으로 임계를 **20관측 이동평균의 3Y 롤링 하위 5% 미만 활성 / 하위 10% 초과 해제(연속 2관측, ⑨와 같은 구조)**로 교체하고 S6을 정량 신호로 이관했다. 롤링 백분위는 0DTE 확산 이후 분포 변화에 스스로 맞춰진다.

*(나) 판별력 점검 의무.* 재캘리브레이션 시점에 판별력(조정 선행력)은 검증되지 않았다. 현재 3Y 창 안의 활성 구간은 2025-02-10~02-28, 2026-05-07~06-18 두 건뿐이어서 통계적 판별이 불가능하다. 분기 정기 점검마다 활성 구간과 이후 지수 경로를 대조하여 기록하고, 판별력 소실이 확인되면 지표 교체를 MS에 회부한다(신호 집합 변경은 SP 정식 개정 사항).

*(다) 결번.* 최신 관측이 **14 달력일(약 10영업일)**보다 오래되면 결번으로 보고 `판정유보(carry)`로 처리하여 직전 확정 상태를 승계한다(엔진 `max_stale_days`). 판정유보가 4주 연속 지속되면 알림 긴급도를 '최고'로 격상하고 소스 설계를 MS에 회부한다.
> **개정 이력**: v3(2026-08-30)은 결번의 비대칭 처리(FRED 계열 승계·CBOE 계열 강등)를 통일했다. 2026-07-15~09-28 결번 기간의 S6은 직전 확정(비활성)을 승계했으며, 결번 직전 3관측 0.81·0.81·0.96은 종전 임계 0.74를 상회했다.

**⑧ 백분위 산출 고정**: 백분위 컷값 = 해당 윈도우 정렬 시계열의 하위 p% 위치 값(선형보간). 판정은 **엄격 부등호**(하위측 `<컷값` / 상위측 `>컷값`)로만 충족. **관측값 = 컷값이면 미충족.** 산출 윈도우·방식이 다른 두 판정이 경합하면 본 항 방식 재실측값이 우선.

**⑨ 레벨 분기 확인 규칙 — 비대칭 밴드 히스테리시스**

레벨 분기는 **활성 임계와 해제 임계를 분리**한다.

| 방향 | 활성 조건 | 해제 조건 | 중립대 |
|---|---|---|---|
| **하위측**(S4 저변동, S7) | 관측 **< p10** 연속 **2관측치** | 관측 **> p20** 연속 **2관측치** | p10 ≤ 관측 ≤ p20 → **직전 상태 유지** |
| **하위측**(S6, 2026-09-28 추가) | 관측 **< p5** 연속 **2관측치** | 관측 **> p10** 연속 **2관측치** | p5 ≤ 관측 ≤ p10 → **직전 상태 유지** |
| **상위측**(S4 공포극단, S8 레벨) | 관측 **> p90** 연속 **2관측치** | 관측 **< p80** 연속 **2관측치** | p80 ≤ 관측 ≤ p90 → **직전 상태 유지** |

- 연속 카운트는 **중립대 진입 시 리셋**된다(활성 연속·해제 연속 모두).
- 확정 조건 미달의 단일 충족은 **'주목'**(카운트 미산입, 알림 가능).
- **변화 분기(±2σ 등 사건형)에는 미적용** — 변화 분기는 발생 즉시 활성 + ③의 30일 유효기간을 따른다.

> **개정 사유 (백테스트 2026-08-24)**: v1의 "대칭 임계 + 연속 2관측치"는 히스테리시스가 아니라 **확인 지연**이며, 경계선 밀집 구간에서 whipsaw를 억제하지 못했다. S4 VIX 2014-01-02~2026-08-20(n=3,209, point-in-time 롤링 컷값) 백테스트 결과 — 구 설계는 59 에피소드 중 **54%가 5영업일 이하**로 종료. 채택안(비대칭 p10/p20, k=2/2)은 41 에피소드, whipsaw **22%**, **진입 지연은 2일로 불변**. 대안인 대칭 k=4/4는 whipsaw 28%이나 탐지가 2일 늦어져 조기경보 목적에 부적합하다.
> **표본 한계 명기 (R5)**: S7은 §2-⑥ 사유로 3Y(에피소드 2건)만 확보되어 통계적 판별이 불가능했다. **S4 결과를 준용**한 것이며, S7 전용 검증은 장기 시계열 확보 시 재실시한다.
> **전환 이력 (2026-08-30)**: 본 항은 2026-08-24 신설 후 부칙 A에 따라 전환기 병행 운용되었고, 2026-08-30 MS 결정으로 **공식 규약으로 확정**되었다. 승인 근거는 위 백테스트이며, 2026-08-24~08-30 구간에 공식(v1) 기준과 본 항(v2) 기준이 7/8로 수렴하여 전환이 카운트 값을 인위적으로 이동시키지 않는다는 점이 확인되었다. **해제 지연은 본 설계가 감수하는 비용이며, 방어 포지션의 유지 기간이 길어지는 방향으로 나타날 것으로 예상되므로 관측 항목으로 추적한다.**

## §3. 단계별 행동 (참고 — 자동화는 알림만, 실행 권한 없음)

| 활성 N | 단계 | 행동 | 점검 빈도 |
|---|---|---|---|
| 0~2 | 정상 | 변경 없음 | 분기 |
| 3~4 | 거품 경계 | 신규 위험자산 보류, OTM Put 1→2% | 월 1회 |
| 5~6 | 거품 후기 | 위험자산 -10%p, 현금·금 +5%p, Bear +10%p 강제 | **주 1회** |
| 7~8 | 폭락 임박 | 위험자산 -20~30%p, 현금·금·단기채 +20~30%p, Bear 80%+, **L5 즉시** | 일 1회 |

> **자동 디리스킹 금지 (SP §0-2, 불가침)**: 자동화 시스템은 **데이터 갱신·알림까지**. 매매 실행 금지. 단계 격상은 *사전 감지*일 뿐 — 결정·실행은 사용자.
> **IPS 정합 확인 의무 (v3 신설)**: 본 표의 조정 폭은 자산군 비중 가이드이며 IPS 한도를 override하지 않는다. 권고 폭을 적용했을 때 IPS 자산군 한도(주식 하한 등)를 이탈하는 경우, **L4는 이탈 사실과 폭을 수치로 보고하고 MS에 회부한다.** 이탈 여부 판단은 보고 사항이며, 실행을 막는 게이트가 아니다.

## §4. Drift 가드

매 실행 시 다음을 확인하고, 불일치 시 **카운트 산출을 중단하지 말고 산출하되 카드·알림에 플래그**한다.

| 체크 | 방법 | 불일치 시 |
|---|---|---|
| **본 파일 stale 여부** | §머리말 "갱신일"이 **60일 초과** | 카드 §메타에 `⚠ 임계표 stale(갱신일 YYYY-MM-DD)` + `02_교환소` 알림 1줄 |
| **카드 ↔ 재산출 불일치** | 이전 카드 N/8 ≠ 본 파일로 재산출한 N/8 | 카드 §메타에 `⚠ 전주 카드 N/8 → 재산출 M/8 (원인: ___)` 명기. **재산출값 채택**(원칙 ①) |
| **판정 유보(carry) 발생** | §1-B B-3 또는 §2-⑦(다) 조건 충족 | 카드에 `⚠ 판정유보(신호명, 사유, 직전확정 승계)` + `02_교환소` 알림 **의무 발령**. 2회 연속 시 긴급도 '최고' |
| **스캔 공백** | 직전 확정일 익영업일 ~ 최신 관측일 사이 미스캔 영업일 존재 | 카드에 `⚠ 스캔 공백 N영업일` 명기 + 해당 구간 소급 스캔 후 결과 병기 |
| **유효 신호 수 병기** (v3 신설) | 8신호 중 당 회차에 **실측으로 확정된 신호 수**를 센다 | 카드 스탬프와 §1 표에 `N/8 (유효 M종)`을 병기한다. M<8이면 결번·유보 신호명을 함께 적는다. **M<8인 회차의 N/8을 8신호 전량 확정 회차의 N/8과 동일하게 취급하지 않는다** |

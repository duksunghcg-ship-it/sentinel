# 예측 커밋 함

데일리 브리핑의 `[예측]` 블록을 파일로 커밋하는 경로임. 수집 모듈(`engine/forecast_ingest.py --inbox forecast/inbox`)이 `*.txt`만 읽고, 그 파일이 처음 커밋된 시각을 등록 시각으로 기록함.

- 파일명: `YYYY-MM-DD.txt` (예측 일자)
- 내용: 브리핑의 `[예측]` 세 줄을 그대로 붙임. 한 파일에 여러 날짜 블록을 넣어도 됨
- 이미 커밋한 파일을 고쳐도 수집 모듈은 최초로 읽은 값을 유지함. 정정은 새 파일이 아니라 이슈 댓글로 경위를 남김

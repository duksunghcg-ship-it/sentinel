# 예측 성적 판독·동결 규칙

**발행** 2026-09-14 · **근거** 예측검증체계 작업지시문 v1.0 과업 ③
**적용 대상** 데일리 브리핑의 일간 방향 예측과 그 성적표(`forecast/SCOREBOARD.md`)

---

## 1. 이 체계가 무엇을 위한 것인가

- 본 체계의 목적은 예측 적중률을 끌어올리는 데 있지 않고, 확신 표현을 실제 성적에 맞추어 보정하고 일간 방향 예측의 존속 여부를 1년 뒤에 수치로 판정하는 데 필요한 증거를 축적하는 데 있음.
- 일간 방향 예측은 구조적으로 기준선을 크게 웃돌기 어려운 영역이므로, 적중률 단독 수치를 성과로 읽지 않음. 성적의 본체는 **기준선 대비 우위** 한 가지임.

## 2. 판독 규칙

| 지표 | 읽는 법 |
|---|---|
| 적중률 | 단독으로 보고하거나 인용하지 않음. 반드시 기준선과 함께 제시함 |
| 기준선 | 같은 대상·같은 채점 기간의 실측 상승일 비율임. 문헌값이나 통념을 대입하지 않고 채점에 사용한 종가 시계열로 직접 산출함 |
| 기준선 대비 우위 | 적중률에서 기준선을 뺀 %포인트 값이며, 이 값이 0 근방이면 예측에 실력이 없다고 읽음 |
| 브라이어 점수 | 낮을수록 좋으나 절대값 자체는 의미가 없고, 기준선 확률만 제시하는 전략 대비 개선도로만 해석함 |
| 보정표 | 확률 구간별 실제 적중률이 구간 중앙값에서 10%포인트 넘게 낮으면 과신으로 판정하며, 이는 확률 표기를 낮추어야 한다는 신호임 |
| 근거분류별 적중률 | 표본 30건 미만 구간은 수치가 산출되더라도 해석 대상이 아님 |
| 보합권·미채점·미기록 | 건수만 병기하며 성적에서 임의로 제외하거나 추정으로 채우지 않음 |
| 휴장 | 예측일에 해당 시장의 거래가 없었던 것으로 확인된 건은 「휴장」으로 표시해 모수에서 제외하고 건수만 병기함 |
| 표본과 영업일 | 표본 수는 예측 건수(하루 최대 2건)이고, 동결 60일·존속 판정 250일은 성적표 첫 줄에 함께 표시되는 채점 영업일 수를 기준으로 함 |

- 표본 수가 작을수록 우위 수치는 크게 흔들림. 기준선 대비 5%포인트의 실력 차이를 통상적인 유의수준과 검정력으로 구별하려면 약 780영업일이, 7%포인트라도 약 400영업일이 필요함. 따라서 초기 구간의 큰 우위는 실력의 증거가 아니라 표본이 작다는 증거로 읽음.

## 3. 동결 규칙

| 규칙 | 내용 |
|---|---|
| 동결 | 누적 60영업일 미만에서는 성적을 보고만 하고, 예측 방식·확률 표현·근거분류 어느 것도 변경하지 않음 |
| 개정 창구 | 예측 방식의 변경은 월간 결정 세션에서만 하며, 주간 브리핑에는 누적 우위 1줄만 싣고 개정을 제안하지 않음 |
| 존속 판정 | 누적 250영업일 시점에 기준선 대비 우위가 +3%포인트 미만이면 일간 방향 예측을 폐지하고, 브리핑을 사실 요약과 임계 근접 알림으로 한정함 |

- 동결 규칙을 두는 이유는 소표본 결과에 반응해 규칙을 반복 조정하면 성적이 개선되는 것이 아니라 과거 표본에만 맞는 형태로 굳어지기 때문임. 과거 임계 설계에서 대칭 임계가 잦은 신호 뒤집힘을 유발해 비대칭 밴드로 교체된 전례가 같은 구조의 실패였음.

## 4. 성적표 이용 규칙

- `forecast/SCOREBOARD.md`의 첫 세 줄은 표본 수, 기준선 대비 우위, 보정 상태이며, 임의 시점에 이 세 줄만 읽으면 체계의 현 상태를 답할 수 있어야 함.
- 주간 브리핑은 이 세 줄 가운데 **기준선 대비 우위 1줄만 인용**하며, 성적을 근거로 예측 방식의 변경을 제안하지 않음.
- 데일리 브리핑 세션은 자신의 성적을 조회하지 않고 본문에 언급하지도 않음. 자기 채점이 예측에 되먹임되면 성적이 예측 대상이 되어 증거로서의 성격을 잃기 때문임.
- 성적표는 자동 생성 파일이므로 직접 편집하지 않음. 수정이 필요하면 채점 모듈을 고침.
